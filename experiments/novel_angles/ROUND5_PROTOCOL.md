Exploratory model comparison on the already used cohorts; baseline results are known. No architecture, hyperparameter, threshold, seed, or stopping criterion may be changed after seeing the new held-out scores. Use [MODELS.md](MODELS.md) for the fixed roster. Report the original kit results separately: its split, duration, decisions, and metrics are not interchangeable with this protocol.

- Reuse prepared recipe FIFs, named channel order, cohort eligibility, the exact Loop 2 identities and seed-42 rotations (20 per cohort). ds007176/RestCog are the two main cohorts. Then apply the same roster without model selection to Dortmund's two-day protocol (baseline pre-task enrollment, baseline post-task calibration, and follow-up pre-task test, as staged by `loop3_dortmund.py:BLOCKS`) and, if feasible, WBCIC-SHU's modified-duration three-day protocol. Label all session and duration limitations.
- Keep the first 24 valid 5-second windows per state on both probe visits and 32 balanced mixed enrollment windows total. Use the WBCIC protocol's 6 and 8, respectively. Paired attempt averages one CE and one OE representation at the same retained rank, single-state attempt averages consecutive representations within one state, then pool the two states. Each arm consumes the same windows, usable duration and number of attempts. No claim that the windows are adjacent in elapsed time or were collected as a live challenge.
- Within each rotation, disjoint claimant/reference/calibration-impostor/final-test-impostor roles. Claimant templates and supervised binary models see only claimant and donor **enrollment** features (32 positives and 32 negatives or the WBCIC budget); deterministic donor slots match Loop 2. Reference-only neural encoders see only the fixed mixed enrollment windows of reference identities; frozen encoders embed each segment before averaging. Score every model on both arms with its own per-claimant cutoff, calibrated on the calibration impostors' windows at empirical ≤1% FAR. Then hold the cutoff fixed on both visits for final-test impostors, with the same impostors at both visits. No test-time normalization.
- Exact Loop 2 cosine and Kit RBF SVM are anchors; LDA uses 50% pooled coordinate variance shrunk toward the scalar mean; logistic regression C=1 and kNN k=5 use identical standardized kit spectral features. Log-Euclidean tangent linear SVM C=1 uses unit-trace regularized window covariances, log transform and centered reference means; MDM uses negative log-Euclidean distance to the claimant's enrollment centroid (verification adaptation, not argmin classification). Average log matrices before scoring both arms.
- Kit base model architectures and hyperparameters are reused. For kit 1D-CNN and BiLSTM-Attention use the documented stabilized wrapper: enrollment-only StandardScaler, clip standardized values to ±12, float32, 15 full-batch Adam steps at 0.001, BCE with logits, gradient norm clipping at 1; check finite inputs, logits, loss, gradients and probabilities. Reuse the kit's four constituent ensemble models (SVM, ExtraTrees, LightGBM, Res-MLP), enrollment-only two-fold OOF rank and stacking with each fold's own scaler. Use four kit-named scalp regions' RBF probabilities for spatial fusion, matching installed names case-insensitively. Report asset and timing dependencies instead of implying cost-free fusion.
- CPU raw DL: EEGNet-, ShallowConvNet-, and DeepConvNet-inspired compact implementations, explicitly not exact Braindecode replicas. Use anti-aliased 250→50 Hz, full available montage, short shared embedding heads and fixed reference-only categorical training. The Siamese model learns a shared 32-d spectral embedding with a supervised contrastive loss on reference enrollment identities only. Raw encoders use CE loss on reference identity labels with 32-d penultimate embeddings for cosine verification. Fixed Adam 0.001, 8 epochs, batch 64, single CPU thread; no tuning. Neural models and ensembles containing Res-MLP use seed 42 as primary; report per-seed results and standard deviations over seeds 42 and 43 for both arms. Use seed 42 for all other methods, including trees. If a fit is nonfinite, fail that analysis and log it rather than silently dropping attempts.

**Post-checkpoint implementation correction (not part of the original prespecification).** Keep LightGBM's minimum leaf size of 20 at 64 training windows and scale it for smaller fits as `min(20, max(2, floor(20 × n_fit / 64)))`. The original setting cannot split the 32-window out-of-fold fits or the 16/8-window WBCIC fits; an enrollment-only diagnostic reproduced constant scores at these sizes. The replacement is based only on fit size, not a held-out metric, and applies to standalone LightGBM and its three ensembles. No split, threshold, endpoint, or other model changes. Use `--lightgbm-review` for the targeted rescore, including the unchanged cosine and RBF SVM anchors for paired bootstrap comparisons; the other ensemble constituents are only refitted as dependencies.
