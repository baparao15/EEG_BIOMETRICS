# Loop 2 analysis plan

This plan was written after the ds007176 lightweight pilot and before inspecting scores from the reconstructed preprocessing or external cohort. The ds007176 rerun is sensitivity analysis on the same participants, not independent confirmation. Do not select decisions on late data.

- Primary endpoint: later-visit EER difference, paired-state mean minus an equal mixture of single-state attempts. Both use the identical mixed-enrollment data and ten usable seconds per attempt (CE+OE vs two CE or two OE). Both consume the exact same first 24 retained 5 s windows per state in exactly 24 attempts. The single-state arm averages consecutive retained windows within each state; the paired arm averages equal retained-window ranks across states. Also report CE and OE separately but not as co-primary tests. Treat an upper 95% subject-bootstrap difference bound below zero as evidence of a directional discrimination gain.
- Secondary endpoints: paired FRR and FAR differences at method-specific thresholds frozen at ≤1% empirical FAR on the calibration visit. Report intervals; no deployment claim unless neither operating error worsens materially (prespecified margins: +2.0 pp FRR and +0.5 pp FAR), and the held-out FAR upper bound is no more than 1%. Also compare FAR for the same held-out impostors on that calibration visit and the later visit; neither set of scores can recalibrate.
- Use the cross-condition kit's seed-42, five-group rotation and per-claimant thresholds on ds007176, and five equal seeded groups on RestCog. Each rotation has disjoint claimant, training, calibration and test identities; two groups supply training negatives. Enrollment receives 160 usable seconds on each dataset: balanced V0/V1 in ds007176; the same total split across both eye states in RestCog session 1 only (no separate second enrollment visit). Use session 2 for calibration and session 3 for late scoring. Report a combined identity × role subject bootstrap conditioned on fitted scores and thresholds (500 draws, seed 177).
- Primary scorer: the pilot's five log-relative-power cosine template; verify with the supplied cross-condition kit's Notebook 07 20-feature spectral bank plus StandardScaler and RBF SVC (C=10, gamma=scale, probability calibration trained only on enrollment). Adapt to budget-matched 10 s probes while keeping enrollment-only reference negatives and using one fitted model across probe policies. Keep the original unmodified 5 s/450 s anchor and new results separate.
- Controls: equal-duration CE–CE and OE–OE repeats, CE–OE contrast, frontal (Fp1/Fp2/F3/F4/F7/F8) and posterior (P3/P4/P7/P8/O1/O2) panels, alpha-excluded relative-power features with denominator re-normalized, and CE/OE acquisition-order strata only wherever both real acquisition timestamps or equivalent ordering metadata exist. Run the alpha exclusion and signed contrast controls with the cosine scorer; run the channel panels with both scorers. Do not invent eye-state order by rearranging a commutative mean. Report which visit/dataset factors are actually identifiable.
- Covariance alignment control: use the pilot's shrinkage-correlation tangent representation and compare equal-budget CE or OE enrollment with state-specific historical (enrollment visits only) or same-visit (independent donors at the exact nominal visit) references against unaligned mixed enrollment. Compare single-state probes with thresholds held fixed and report paired probes as secondary. Do not infer noninferiority from overlap or a nonsignificant difference.
- Use exact dataset snapshot hashes. Validate signal convergence on the committed 40 FIFs by event-set Jaccard, channel-aligned sample correlation and standardized waveform RMSE on shared event starts. A median correlation ≥0.995 and RMSE ≤0.10, together with median event Jaccard ≥0.95, are minimal criteria to describe a near-equivalent reconstruction; otherwise label the full rerun exploratory under a different preprocessing implementation.
- RestCog is independent replication if complete readable pairs survive both preprocessing and the locked scoring protocol. Report missing/unreadable inputs, without replacing later outcomes or selecting subjects on scores. Dortmund has only two visits; defer unless a separate defensible calibration dataset/unit is available, rather than calling a modified protocol a replication.
